# TikTok Structures

## Structure 1 — Fast Build

0-3s:
Strong hook

3-10s:
Show build/problem

10-25s:
Show workflow/process

25-40s:
Show result

40-50s:
Reflection/lesson

50-60s:
Next step

---

## Structure 2 — Honest Journey

Hook:
“I’m learning AI by building in public.”

Then:
- what happened today
- what failed
- what worked
- current screen recording
- lesson learned

---

## Structure 3 — Tool Demo

Hook:
“I tested GPT-5.5 for ___.”

Show:
- prompt
- generation
- mistakes
- output
- final result

---

## Structure 4 — Screen Recording Style

- cursor movement
- terminal activity
- code appearing
- before/after
- voiceover reflection
- cinematic zooms

---

## Editing Notes

- fast pacing
- subtitles always
- movement every 2-3 seconds
- avoid long intros
- show proof immediately
