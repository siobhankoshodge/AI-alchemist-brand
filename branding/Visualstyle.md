# AI Alchemist Visual Style

## Emotional Feel

The UI should feel:

- calm
- futuristic
- creative
- empowering
- safe to explore
- cinematic
- intelligent but approachable

Avoid:

- corporate SaaS feel
- harsh enterprise styling
- clutter
- hype aesthetics

---

# UI Style

- dark mode first
- soft glow accents
- spacious layouts
- large typography
- clean cards
- subtle gradients
- modern creator aesthetic

---

# Colour Direction

Primary:

- deep navy
- charcoal
- black-blue

Accent:

- teal glow
- cyan
- soft purple
- emerald highlights

---

# Typography Feel

- bold headlines
- clean readable body text
- modern
- confident but calm

---

# Inspiration

The interface should feel like:

- an AI creator studio
- a modern creative workspace
- calm futuristic productivity
- thoughtful experimentation

Not:

- corporate dashboard software
- crypto UI
- hacker aesthetic
